# Case Study Repository

A collection of weekly case study notebooks and assignments organized by week. This repository is designed for learning, analysis, documentation, and exploring practical data scenarios through structured case studies.

## Overview

This project contains a series of case study folders named by week and case study number, such as:

- W1_Case_Study_1
- W1_Case_Study_2
- W2_Case_Study_1
- W2_Case_Study_2
- W3_Case_Study_1
- W3_Case_Study_2
- W4_Case_Study_1
- W4_Case_Study_2

The repository is primarily notebook-based and is intended to support coursework, hands-on practice, and documentation of analytical work.

## How to Use

1. Open the relevant week folder.
2. Review the notebook(s) inside.
3. Run the cells in the notebook to explore the analysis.
4. Use the folder structure to track progress across weekly case studies.
