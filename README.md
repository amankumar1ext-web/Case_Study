# Case Study Repository

This repository contains a collection of case study notebooks organized by week. Each folder focuses on a different case study exercise and is intended for learning, analysis, and documentation work.

## Repository Overview

- The project primarily contains Jupyter Notebook files.
- Content is grouped by week and case study number.
- Each folder is a self-contained topic or assignment.

## Folder Structure

```text
Case_Study/
├── W1_Case_Study_1/
├── W1_Case_Study_2/
├── W2_Case_Study_1/
├── W2_Case_Study_2/
├── W3_Case_Study_1/
├── W3_Case_Study_2/
├── W4_Case_Study_1/
├── W4_Case_Study_2/
└── README.md
```

## Folder Details

- W1_Case_Study_1: Week 1, Case Study 1
- W1_Case_Study_2: Week 1, Case Study 2
- W2_Case_Study_1: Week 2, Case Study 1
- W2_Case_Study_2: Week 2, Case Study 2
- W3_Case_Study_1: Week 3, Case Study 1
- W3_Case_Study_2: Week 3, Case Study 2
- W4_Case_Study_1: Week 4, Case Study 1
- W4_Case_Study_2: Week 4, Case Study 2

## How to Use

1. Open the relevant week folder.
2. Review the notebook(s) inside.
3. Execute or study the analysis according to the assignment instructions.

## Notes

This repository is structured for educational case-study work and may continue to grow with additional weeks or assignments in the future.
